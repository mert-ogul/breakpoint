# ACT deployment stress benchmark: saved results

Saved results of the exploratory run (simulation only). Start with
[METHODOLOGY.md](METHODOLOGY.md); reproduce with [REPRODUCE.md](REPRODUCE.md); open
[report/index.html](report/index.html) or [report/report.md](report/report.md) for results.

| Path | Contents |
| --- | --- |
| `report/` | `index.html`, `report.md`, SVG and PNG plots, `data_index.json` (generated by `scripts/render_benchmark.py`) |
| `media/` | `comparison.gif`, `comparison.mp4`, `social-preview.png`, `selection.json`, `verification.json` |
| `data/episodes/episodes.jsonl` | One compact record per episode and condition (600 rows). Canonical raw source is named in each row's `source_report` |
| `data/summaries/` | Saved experiment summaries, verbatim (four axes; the device replay axis has none) |
| `data/protocol/` | Config, protocol lock, run records, and the five experiment plans, verbatim |
| `data/identities/`, `data/validation/` | Model hashes, export validation (FP32 and INT8), corpus descriptors |
| `data/profiles/<device>/` | Raw 1000-sample latency profile, run metadata with telemetry, completion record |
| `data/historical/` | Per-condition provenance and planned settings, verbatim |
| `data/large_evidence.json` | Size and SHA-256 of evidence that is deliberately not in the repository |
| `data/manifest.json` | SHA-256 of every packaged file |

## Episode record fields

`episodes.jsonl` keeps outcome, seeds, step and inference counts, reward sums, the constant delay
or replay window (`trace_window_start`, `consumed_trace_indices`, `consumed_delays_s`), image
settings, and `source_report`. Per-step actions and observations are not copied.

## Large evidence (not in the repository)

The control-step logs are in the original run directory, which is ignored by git:
`outputs/v1/full/axes/*/conditions/*/run_report.json` and
`outputs/v1/full/shared_baselines/default_fp32_native_L0/run_report.json` (about 243 MB; the
`episodes.jsonl` files beside them duplicate the same episodes and add 147 MB). The exported ONNX graphs and corpora
are in `artifacts/export/act-v1`. Sizes and hashes are in `data/large_evidence.json`.

## Historical paths

Verbatim protocol, summary, and provenance files contain absolute paths from the machine that
produced them. They identify where the evidence came from; they are not links. Every link in
the report and in this directory is relative.
